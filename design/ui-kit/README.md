# UI-кит «Терем» · v1

[Визуальный лист](./terem-ui-kit.png) — референс внешнего вида. Значения ниже и `src/constants/terem-tokens.ts` — источник точных параметров для вёрстки: мелкие подписи на сгенерированном PNG могут быть неточными.

## Токены

| Назначение | Значение |
| --- | --- |
| Основной текст, контур, кнопка | `#111111` |
| Акцент, цена, активный пункт | `#FF4D00` |
| Фон | `#FFFFFF` |
| Сетка на фоне | `#E8E8E8` |
| Вторичный текст | `#6B6B6B` |
| Неактивное состояние | `#B8B8B8` |
| Доступно / успех | `#00C853` |
| Ошибка | `#D92D20` |

Отступы: **4 / 8 / 12 / 16 / 24 / 32**. Минимальная зона касания: **48 dp**. Высота основной кнопки: **56 dp**, поля: **52 dp**. Обычная рамка: **1 dp**. У карточки чёрная жёсткая тень со смещением **5 dp**.

Типографика: заголовок экрана **48/49, Black Italic**; заголовок секции **28/31, Black Italic**; название карточки **22/25, Black Italic**; основной текст **16/23**; подпись **14/18 Bold**; вспомогательный текст **12/16**. В коде пока используется системный шрифт с нужной насыщенностью и наклоном. Перед финальным визуальным совпадением подключите лицензированный узкий жирный курсивный шрифт и проверьте переносы на Android и iOS.

## Компоненты

| Элемент | Файл | Правило |
| --- | --- | --- |
| Кнопка | `src/components/ui/terem-button.tsx` | Основная чёрная, вторичная контурная, акцентная оранжевая; есть disabled и нажатие |
| Текст | `src/components/ui/terem-text.tsx` | Варианты `display`, `section`, `cardTitle`, `body`, `label`, `caption` |
| Поле ввода | `src/components/ui/terem-input.tsx` | Обычное, фокус, ошибка; подпись и текст ошибки |
| Карточка | `src/components/ui/terem-card.tsx` | Рамка и жёсткая тень; наполнение определяет экран |
| Статус | `src/components/ui/status-badge.tsx` | Доступно, активно, недоступно |
| Выбор срока/категории | `src/components/ui/terem-choice-group.tsx` | Один выбранный вариант, минимум 48 dp |
| Прогресс | `src/components/ui/step-progress.tsx` | Для получения и возврата; текущий шаг из общего числа |

Пример:

```tsx
import { TeremButton } from '@/components/ui/terem-button';
import { TeremChoiceGroup } from '@/components/ui/terem-choice-group';
import { StepProgress } from '@/components/ui/step-progress';
import { TeremCard } from '@/components/ui/terem-card';
import { TeremText } from '@/components/ui/terem-text';

<StepProgress current={2} total={3} />
<TeremCard><TeremText variant="cardTitle">ФОТОАППАРАТ</TeremText></TeremCard>
<TeremChoiceGroup
  accessibilityLabel="Срок аренды"
  options={[{ value: '1h', label: '1 час' }, { value: '3h', label: '3 часа' }]}
  value={duration}
  onChange={setDuration}
/>
<TeremButton label="Взять в аренду" trailingArrow onPress={handleRent} />
```

## Шаблон экрана

Безопасная область → верхняя строка с названием и возвратом → большой заголовок → основной контент → нижняя зона действий. Основное действие всегда одно. На шагах получения и возврата показывайте номер шага и ссылку на помощь. Состояния загрузки, ошибки, недоступности и отключённой кнопки проектируйте для каждого действия, которое ждёт ответа сервера.

Пунктирную сетку, фото вещей и полосы безопасности лучше сделать отдельными фоновыми/декоративными элементами. Они не должны перехватывать касания и ухудшать читаемость. Для длинного текста, маленьких телефонов и увеличенного системного шрифта экран должен прокручиваться.

Этот набор — основа **светлой темы**, показанной в макетах. Тёмную тему следует проектировать отдельными цветовыми токенами после утверждения её макетов. PNG не следует использовать как готовый интерфейс приложения.
