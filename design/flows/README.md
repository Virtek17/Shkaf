# Цепочка аренды: макеты и поведение

Эти PNG — визуальные референсы для вёрстки. Суммы, время, пункт, ячейка и идентификатор на картинках примерные: в приложении берите их из состояния заказа/ответа сервера. Фото и надписи внутри изображений не следует встраивать как готовый экран.

## Порядок экранов

1. Уже есть: карточка вещи → `01-booking-payment-success.png`, экран «Подтвердите аренду». Покажите выбранный срок, начало, срок возврата, пункт и итог. Кнопка ведёт к оплате.
2. «Оплата аренды». Покажите заказ и поддерживаемые способы оплаты. После успешного ответа платёжного сервиса откройте результат; при ошибке оставьте заказ доступным для повторной попытки.
3. «Вещь забронирована». Подтверждённый заказ, место и крайнее время получения. Кнопка ведёт к уже существующему шагу 1 получения.
4. Уже есть: получение, шаг 1/3 — открыть ячейку → `02-pickup.png`, шаг 2/3 — забрать вещь и проверить комплект → шаг 3/3 — закрыть ячейку и дождаться подтверждения → результат «Вещь у вас». Аренда становится активной только после подтверждения закрытия.
5. Уже есть: активная аренда → уже существующий возврат, шаг 1/3 — открыть ячейку → `03-return.png`, шаг 2/3 — положить полный комплект → шаг 3/3 — закрыть ячейку и дождаться проверки → уже существующий экран «Возврат завершён».

## Состояния, которые нужны при вёрстке

- Для каждой операции с ячейкой: ожидание, успех, ошибка и повторная попытка. Не переводите пользователя на следующий шаг до подтверждения от сервера.
- Для оплаты: ожидание, успешный платёж, ошибка или отмена. Не показывайте «Вещь забронирована» до подтверждения заказа сервером.
- Для получения и возврата: ссылка «Возникла проблема» ведёт к обращению в поддержку с номером аренды и этапом процесса.
- Если время на получение истекло или вещь стала недоступна, покажите отдельное состояние заказа с понятным дальнейшим действием.

## Уточнения к нарисованным PNG

Генерация изображений может ошибаться в мелком тексте и индикаторах. На **правом экране `03-return.png` должен быть «Шаг 3 из 3»**. На шаге 2 получения ячейка открыта и вещь уже у пользователя; на шаге 2 возврата ячейка открыта и пользователь кладёт вещь внутрь. Текст, порядок и переходы из этого файла имеют приоритет над надписями на PNG.

Способы оплаты и время «получить до 12:15» на первом PNG — концепт. Оставьте только реально поддерживаемые методы и рассчитывайте срок получения по бизнес-правилам сервера.
